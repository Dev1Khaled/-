# موقع خالد عزالدين الشخصي

موقع ويب شخصي احترافي يعرض المهارات والأعمال والخبرات في مجال البرمجة وتطوير الويب والتطبيقات.

## 🎯 المميزات

- **تصميم حديث واحترافي**: واجهة مستخدم نظيفة وأنيقة مع تأثيرات بصرية احترافية
- **استجابة كاملة (Responsive)**: يعمل بشكل مثالي على جميع الأجهزة (الهاتف، الجهاز اللوحي، الكمبيوتر)
- **محتوى عربي كامل**: جميع النصوص والمحتوى باللغة العربية
- **أداء عالي**: موقع سريع وخفيف الحجم
- **سهل التخصيص**: يمكن تعديل المحتوى والألوان بسهولة

## 📋 الأقسام الرئيسية

1. **الصفحة الرئيسية**: تعريف شامل بخالد وأهدافه
2. **من أنا**: نبذة شخصية وخلفية احترافية
3. **المهارات**: عرض المهارات الرئيسية والتقنيات المستخدمة
4. **الأعمال**: معرض للمشاريع والأعمال السابقة
5. **التواصل**: نموذج اتصال وروابط التواصل الاجتماعي

## 🛠️ التقنيات المستخدمة

- **React 19**: مكتبة JavaScript لبناء واجهات المستخدم
- **TypeScript**: لغة برمجة توفر أماناً أكبر للأنواع
- **Tailwind CSS 4**: إطار عمل CSS حديث لتصميم سريع
- **Vite**: أداة بناء سريعة وفعالة
- **Wouter**: مكتبة توجيه خفيفة الوزن
- **Lucide React**: مجموعة أيقونات حديثة
- **shadcn/ui**: مجموعة مكونات React عالية الجودة

## 📦 المتطلبات

- Node.js (الإصدار 16 أو أحدث)
- npm أو pnpm أو yarn

## 🚀 كيفية التشغيل

### 1. استنساخ المشروع

```bash
git clone https://github.com/yourusername/khaled-portfolio.git
cd khaled-portfolio
```

### 2. تثبيت المتطلبات

```bash
# باستخدام npm
npm install

# أو باستخدام pnpm
pnpm install

# أو باستخدام yarn
yarn install
```

### 3. تشغيل خادم التطوير

```bash
# باستخدام npm
npm run dev

# أو باستخدام pnpm
pnpm dev

# أو باستخدام yarn
yarn dev
```

سيتم فتح الموقع تلقائياً على `http://localhost:5173`

### 4. بناء النسخة الإنتاجية

```bash
# باستخدام npm
npm run build

# أو باستخدام pnpm
pnpm build

# أو باستخدام yarn
yarn build
```

## 📝 تخصيص المشروع

### تعديل المحتوى

جميع المحتويات موجودة في ملف `client/src/pages/Home.tsx`:

- **البيانات الشخصية**: عدّل الأسماء والأوصاف
- **المهارات**: أضف أو احذف المهارات من قائمة `skills`
- **المشاريع**: عدّل قائمة `projects` لإضافة أعمالك الخاصة
- **معلومات التواصل**: حدّث بريدك الإلكتروني ورقم هاتفك

### تعديل الألوان والتصميم

- **الألوان الرئيسية**: موجودة في `client/src/index.css`
- **الخط**: يستخدم الموقع خط Poppins (يمكن تغييره في `client/index.html`)
- **التأثيرات البصرية**: يمكن تعديلها في ملفات CSS و Tailwind

### إضافة صور مخصصة

لإضافة صورك الخاصة:

1. احفظ الصور في `/home/ubuntu/webdev-static-assets/`
2. استخدم الأداة: `smart_kh --webdev path/to/image.png`
3. استخدم الرابط المُرجع في الكود

## 🌐 النشر

يمكن نشر الموقع على عدة منصات:

### Vercel (موصى به)

```bash
npm install -g vercel
vercel
```

### Netlify

```bash
npm install -g netlify-cli
netlify deploy --prod --dir=dist
```

### GitHub Pages

1. عدّل `vite.config.ts` وأضف: `base: '/khaled-portfolio/'`
2. شغّل: `npm run build`
3. ارفع المجلد `dist` إلى فرع `gh-pages`
